# 🧮 Математический контрольный тренажёр

Интерактивный веб-тренажёр по математике в виде школьной тетради в клетку. Разработан для быстрой отработки вычислительных навыков на уроках и дома с телефона или компьютера.

## 🔗 Рабочая версия сайта
Открыть тренажёр в браузере: **https://my-trenezer.netlify.app/**

## ✨ Основные возможности
* **Тетрадь в клетку.** Примеры оформляются по школьным стандартам (в столбик, уголком, в строчку или с разложением на разряды).
* **Умный автопереход.** Курсор автоматически перемещается по клеткам при вводе цифр, поддерживается удобное стирание и проверка по клавише `Enter`.
* **Мгновенная проверка.** Ошибочные клетки подсвечиваются красным, правильные — зелёным, а в конце сессии формируется итоговая карточка с результатом, датой и временем выполнения.
* **Работает без интернета.** После загрузки страницы тренажёр полностью автономный и не требует подключения к сети.
* **Лёгкий код.** Весь проект написан на чистом HTML, CSS и JavaScript без сторонних библиотек.

## 🚀 Запуск локально
Достаточно скачать файл `index.html` и открыть его в любом современном браузере.
